Data notice

The hovered X handle is sent to api.fxtwitter.com to fetch its public replies — in every mode. In Heuristic mode this is the only off-device call; scoring runs on your device.

Data notice — AI mode

Proxy mode sends the handle, the computed feature object and up to 12 reply snippets (truncated to 400 characters, with third-party handles, URLs and email-like addresses best-effort scrubbed) to the hosted Worker. The Worker forwards a normalised version to the configured AI models and may keep results in a shared cache for 48 hours. The hosted service allows 200 analyses per install per day.

BYOK sends the same payload to the endpoint you configure, authorised by your API key. The operator of that endpoint controls how the data is used and retained — read their terms and limits. Their limits apply; the hosted 200-per-day limit does not. The author never receives the data.
